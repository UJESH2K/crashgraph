        A lander that keeps its mind in a graph
        
        
        
          A reinforcement-learning agent normally ends up as a neural network: a block of weights
          that lands the craft but cannot tell you anything about it. When it crashes you can
          retrain, but you cannot ask why. There is nothing in there to query.
        
        
        
        
          crashgraph removes the network. The pilot has no weights and no model file. Before every
          engine decision it reads FalkorDB; after every attempt it writes back what happened. The
          policy is the graph — about a hundred thousand state tiles, the situations the
          craft passes through, and the transitions between them. The memory it flies on is the
          same memory you can interrogate, with ordinary Cypher.
        
        
        
        
          
        The testdelete the graph and the craft must fail completely
        
          
        PhysicsGymnasium LunarLander-v3 on Box2D, unmodified

        Ares and Titan were seeded with Luna's tiles, then trained on their own
            physics. Harder air means a lower landing rate on the same budget.
        
        
        

        
        
          
        How the memory grew
        
          
          
        New situations appear quickly, then level off: the craft stops meeting
            states it has never seen, which is when the landing rate climbs.

        Nothing here is hand-tuned. The physics, the reward and the learning rule
          are standard and published; the graph work is FalkorDB's own algorithms.
